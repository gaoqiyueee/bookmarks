⚡ 开启云同步（多人共享）

配置 Firebase 后，所有人打开同一页面数据实时同步。完全免费，按以下步骤操作：

1
创建 Firebase 项目
访问 console.firebase.google.com → 点击「新增专案 / Add project」→ 输入项目名（如 bookmark-house）→ 关闭 Google Analytics → 建立。
2
开启 Firestore 数据库
左侧菜单展开「Build（构建）」→ 点击「Firestore Database」→ 点击「Create database（建立资料库）」→ 选「Start in test mode（测试模式）」→ 区域选 asia-east2（香港）→ 点 Enable。
⚠️ 测试模式 30 天后到期，到期前进 Rules 把日期改大就行：allow read, write: if request.time < timestamp.date(2099,1,1);
3
获取配置代码
点左上角「齿轮图标 ⚙️」→「Project settings（项目设置）」→ 滚到「Your apps（您的应用程式）」→ 点「</> 网页图标」→ 输入应用名称 → 点「Register app」→ 在 firebaseConfig = { ... } 里复制大括号内全部内容。
4
粘贴配置，保存即生效
粘贴后点「保存并连接」，右上角变成 🟢 已同步即成功。
如果要把配置写进 HTML 文件一起放到 GitHub，请看下方「写入文件」按钮。
💾 本地备份 / 恢复

不依赖任何第三方服务，随时把全部数据导出为 JSON 文件保存到本地，换设备或清除浏览器时可一键恢复。

☁️ WebDAV 同步（国内可用）

支持 TeraCloud、坚果云等任意 WebDAV 服务，数据存为一个 JSON 文件，多端共享。
